Built and working

The machine is in good shape

A single fleet surface at /ops/standing, phone-operable and repo-filtered, deriving every verdict from live row counts. A Ralph autonomous loop with single-flight control, attempt caps and a supervised-path merge boundary. 63 registered guardrails with severity semantics, proof-of-firing fixtures and a registry that fails closed. A PII gate on pre-commit, commit messages, every PR and weekly. A design system published to npm with a Figma sync foundation. Visual regression now gated on pull requests and on main.

That is a real platform. Measured against the scope test, it is also mostly indirect.
