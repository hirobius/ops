# docs/archive — history, not context

Superseded plans, specs, session captures and reports. Everything here was
current once; none of it is now.

**Do not read this to get oriented.** Start at `docs/ai/HANDOFF.md`. For why a
decision was made, start at `docs/DECISIONS.md`.

Archived 2026-09-15:

- `superpowers/` — 17 plans and specs from 2026-03 to 2026-05, all for work that
  already shipped. `docs/specs/` is the live convention; both
  `FRONTIER-DOCTRINE.md` and `docs/specs/README.md` already described this
  directory as archive before it was moved here.
- `signal/` — `SIGNAL.md` and a May session capture.
- Dated snapshots — a figma-plugin state file, a bookmarks insight dump, a
  hidden-UI audit, a figma-sync plan, a control inventory, a motion survey.

Nothing was deleted. `git mv` reverses any of it, and `git log --follow` reaches
the full history of every file.

One file was moved here and **put back**: `AI_DECISION_LEDGER.md`. It stopped
being written in July, but eleven live documents cite it — stale and
unreferenced is the bar for archiving, and it only met half.
